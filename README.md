# X-All Power Scrubber (Old Q1 Model Vs. S8 New Model Summary) KBS

A self-contained, responsive product knowledge base arranged to match the supplied Notion screenshot: a page title and summary, database-style view tabs, and a compact product table.

## Preview

Open `index.html` in a browser. All pages and images work locally without an internet connection.

## Publish

This repository is configured for GitHub Pages. The live site URL will be listed under Settings > Pages once deployment completes.

## Included pages

- Product database view with search, status filter, and sorting
- Tips/Accessories Gallery, Device Gallery, and Use & Controls views
- Dedicated Old vs New Q1 and S8 comparison view
- Manuals and packaging resources

High-resolution accessory and manual links open the supplied Google Drive files in a new tab. High-resolution product images link to the supplied Drive folder.

## Source and scope notes

- The comparison table is transcribed from the supplied image and retains the COGS figures that the user authorized for public publication.
- Product assets are optimized versions of the user-provided materials.
- The linked Notion page itself remained inaccessible; the uploaded screenshot was used as the layout reference.
